About

Suryabindu Encryption System (SBES) is an experimental cybersecurity encryption framework that combines:

  • Password-based encryption
  • Random salt generation
  • Solar coordinate entropy
  • 63-character SolarKey generation
  • PBKDF2-HMAC-SHA256
  • Fernet AES encryption

Solar Security Engine

SBES uses live solar coordinates:

Theta = Sun Azimuth
Phi = Sun Elevation

These values are transformed into a unique 63-character SolarKey.

Password + Salt + SolarKey

Encryption Workflow

1. Read file
2. Generate solar coordinates
3. Create Solar63 key
4. Generate random salt
5. Derive secure key
6. Encrypt using Fernet
7. Save .sbes file
